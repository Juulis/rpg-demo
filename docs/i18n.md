# i18n (svenska/engelska), issue #20

Svenska är källspråket. Allt som visas för spelaren hämtas från språkfiler eller översatt data, aldrig från hårdkodade strängar. Det som saknas på engelska faller tillbaka på svenska. I dev-läge loggas då en varning, en gång per nyckel.

## Klasser (`src/i18n`)

| Klass                   | Ansvar                                                                                                                                                                      |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LocaleManager`         | Aktivt språk, `t(key, params)`, sparar valet i `localStorage['rpg_locale']`, skickar `locale_changed {locale}` på bussen och har `onChange()` för vyer. Är en `GameModule`. |
| `Translator`            | Uppslagning i `sv.json`/`en.json`, `{param}`-interpolation och pluralisering (`Intl.PluralRules`, param `count`).                                                           |
| `LocalizedTextResolver` | Löser `LocalizedText` i data: sträng, `{sv, en}` eller `{key, params}`.                                                                                                     |
| `DataLocalizer`         | Lägger Speldesigns en-overlays ovanpå svensk designdata, per fil och id.                                                                                                    |
| `DataOverlayLoader`     | Laddar `src/data/i18n/<locale>/*.json` via `import.meta.glob` och skickar dem till `DataLocalizer`.                                                                         |
| `VoiceResolver`         | Röstfiler: `<BASE_URL>assets/audio/npc/<locale>/<npc>/<replik-id>.ogg`. Saknas en-filen används sv.                                                                         |

`LocaleManager` skapas först i `src/main.ts`, registreras som modul och skickas via konstruktorn till varje modul som visar text. Inga globaler.

```ts
const i18n = new LocaleManager();
const modules = [i18n, new SaveModule(i18n), new MenuModule(save, i18n), new AudioModule(i18n), new MapModule(i18n)];
```

## UI-text: nycklar i `src/i18n/sv.json` och `en.json`

- Nycklar är punktseparerade (`menu.continue`). Typen `Key` härleds från `sv.json`, så en nyckel som inte finns där ger ett kompileringsfel.
- Interpolation: `"Radera {name} för alltid?"` med `t('menu.delete_confirm', { name })`.
- Plural: `{ "one": "{count} ledig plats", "other": "{count} lediga platser" }` med `t('menu.slots_free', { count })`.
- Lägg till en nyckel i `sv.json` först och sedan i `en.json`. Saknas den i `en.json` används svenskan.

Nyckelstruktur idag (toppnivå = modul):

```
common.*   titel, avbryt, tillbaka
lang.*     språkväljaren (språknamnen visas alltid på respektive språk)
classes.*  klassnamn per klass-id
menu.*     hjälteval, skapa hjälte, radera (bekräftelse), lediga platser (plural)
errors.*   namnvalidering och fulla platser
save.*     sparikonen
audio.*    volym och ljud av/på
map.*      zoner, områden, mål, portaletiketter, teckenförklaring
```

Andra moduler lägger till egna toppnivåer: `tooltip.*`, `hud.*`, `lore.*` (UI-ramar), `quest.*` (UI-ramar) och `dialog.*` (knappar).

## Speldata (föremål, monster, lorebok, dialoger, quests)

Innehållstext ligger **inte** i `sv.json`. Den ligger i designdatan, och översättningen är en parallell fil.

**Format (bestämt av Speldesign):** `design/i18n/en/<samma filnamn som den svenska filen>.json`. Varje fil är en platt map från id till textfält, med samma fältnamn som i den svenska filen:

```json
// design/i18n/en/foremal_bas.json
{
  "ristarens_mejsel": { "namn": "The Carver's Chisel", "beskrivning": "..." }
}
```

- Bara textfält översätts. Siffror, id:n och referenser ligger kvar i den svenska filen.
- Saknas en post eller ett fält används svenskan (varning i dev-läge).
- I spelet kopieras filerna till `src/data/i18n/en/` och laddas av `DataOverlayLoader`.

Användning i kod (Utvecklare: tooltips, föremål, monster):

```ts
const data = new DataLocalizer(i18n);
new DataOverlayLoader(data).loadBundled();
const item = data.localize('foremal_bas', id, svItem); // kopia med engelska textfält
const name = data.field('monsterfamiljer', id, 'name', svName); // ett fält
i18n.onChange(() => tooltip.rerender()); // eller lyssna på bus 'locale_changed'
```

För enstaka texter direkt i data (t.ex. nya poster) kan `LocalizedText` användas: `"namn": { "sv": "Svärd", "en": "Sword" }` eller `{ "key": "tooltip.socket" }`. Lös dem med `LocalizedTextResolver.resolve()`.

### Det här fyller Speldesign i

| Svensk fil                                         | en-overlay                     | Textfält (samma namn som i den svenska filen)           |
| -------------------------------------------------- | ------------------------------ | ------------------------------------------------------- |
| `foremal_bas.json`                                 | `i18n/en/foremal_bas.json`     | namn, beskrivning                                       |
| `affix.json`, `set.json`                           | samma filnamn                  | namn och bonustexter                                    |
| `monsterfamiljer.json`                             | `i18n/en/monsterfamiljer.json` | name, beskrivning                                       |
| `klasser.json`                                     | `i18n/en/klasser.json`         | name, role                                              |
| `lorebok.json`                                     | `i18n/en/lorebok.json`         | titel, text                                             |
| `quests.json`, `rykten.json`, `npc.json`           | samma filnamn                  | titlar, beskrivningar, namn                             |
| `dialoger.json`                                    | `i18n/en/dialoger.json`        | replik-text per replik-id (ersätter `dialoger_en.json`) |
| `stader.json`, `portal_by.json`, `spawnzoner.json` | samma filnamn                  | namn på städer, zoner och områden                       |

Exakta fältnamn är de som står i respektive svensk fil. Overlayen följer dem 1:1.

## Röster (NPC)

`VoiceResolver.resolve(npc, replikId)` ger `<BASE_URL>assets/audio/npc/<locale>/<npc>/<replik-id>.ogg`. Svenska filer ligger i `public/assets/audio/npc/sv/...` och engelska i `.../en/...`. Saknas en en-fil används sv.

## Asset-sökvägar och BASE_URL

TS-versionen byggs till `/rpg-demo/next/` (Vite `base`), och 3D-versionen ligger kvar på roten. Alla asset-URL:er byggs därför med `import.meta.env.BASE_URL` (`src/core/assets.ts`, `VoiceResolver`). Använd aldrig absoluta `/assets/...`.
